# 📊 SassDash — Admin Dashboard

A modern, fully functional admin dashboard built with **React**, **TypeScript**, and **shadcn/ui**, designed with a clean and accessible component-based architecture.

---

## 🚀 Live Demo

> https://sass-dashbord1.vercel.app/

---

## ✨ Features

- 📋 Clean admin layout with sidebar navigation
- 🧩 Reusable UI components using shadcn/ui
- 🔷 Full TypeScript coverage across the entire codebase
- ⚡ Lightning-fast development build with Vite + HMR
- 🧹 Code quality enforced with ESLint (strict TypeScript rules)
- 📱 Responsive design for all screen sizes

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React 18 | UI library |
| TypeScript | Type safety |
| Vite | Build tool & dev server |
| shadcn/ui | Component library |
| Tailwind CSS | Utility-first styling |
| ESLint | Code quality & linting |

---

## 📁 Project Structure

```
sassDash/
├── public/
├── src/
│   ├── components/      # Reusable UI components
│   ├── pages/           # Dashboard pages
│   ├── lib/             # Utilities and helpers
│   └── main.tsx         # App entry point
├── components.json      # shadcn/ui config
├── tsconfig.json
└── vite.config.ts
```

## ⚙️ Getting Started

```bash
# Clone the repo
git clone https://github.com/Bassam-WD/sassDash.git

# Navigate into the project
cd sassDash

# Install dependencies
npm install

# Start the development server
npm run dev
```

---

## 📦 Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server with HMR |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint checks |
